# Contributing to MEES - The One

Thank you for your interest in contributing to MEES. This is a constitutional framework for regenerative economics, not a software project. Contributions are intellectual, legal, philosophical, and practical.

## How to Contribute

1. **Read the 1-Page Guide:** Start with `START_HERE_Participant_Guide.md` to understand the framework in plain language.
2. **Review the Constitution:** Read `Step_01_Constitutional_Foundation.md` for the immutable principles.
3. **Submit a Challenge or Proposal:** Use the GitHub Issues page to:
   - Challenge a specific clause or measurement.
   - Propose a new amendment.
   - Offer legal, economic, or philosophical analysis.
   - Share relevant case studies from your field.

## The 90-Day Commentary Period

We are currently in a formal 90-day commentary period (until **November 29, 2026**). Any feedback submitted during this period will be considered for ratification.

## Standards of Contribution

- **Provenance Required:** All submissions must include source, methodology, and rationale.
- **Evidence-Based:** Claims must be backed by reasoning, data, or logical argument.
- **Respectful Discourse:** Personal attacks or ideological purity tests are not welcome.

## Legal Acknowledgment

Please note that MEES is a voluntary constitutional proposal. Adoption does not supersede existing national or contract law. See `Step_08_Community_Adoption_Protocol.md` for the Jurisdictional Compatibility Principle.
